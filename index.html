⚡ 4-Piece Skin Set Bonuses (Wearing 4x Same Family on Body Slots)

🦌 Deer Hide Set (Melee Builds)

After dealing Impact DMG (melee hit while sprinting), Crit DMG +15%.

🐺 Wolf Skin Set (Physical/Team)

Weakspot DMG +6% when in a team with more than 1 player.

🐰 Rabbit Fur Set (Physical / Airborne)

Weakspot DMG +20% while airborne/mid-air.

🐐 Wool / Goat Set (Elemental Builds)

Status DMG +2% for every member in a team (Max +6%).

🐻 Bear Skin Set (Elemental Builds)

Frost & Shock DMG +6% when temperature is below 10°C.

🐊 Crocodile Hide Set

Weakspot DMG +12% while invisible.

🦊 Fox Skin Set

Physical DMG +8% when not in combat.

🐃 Cowhide Set (Melee Builds)

Impact attacks consume all Stamina, increasing DMG by 1% per point consumed.

Mask: Starfall Down

Mask: Starfall Cowhide

+8% Weapon DMG airborne + 8% on high stamina (Total 16%).

Mask: Lucky Rabbit Fur
